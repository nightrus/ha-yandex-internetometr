# Яндекс Интернетометр для Home Assistant

Замер скорости интернета (загрузка, отдача, пинг) по серверам
[Яндекс.Интернетометра](https://yandex.ru/internet) с карточкой для дашборда.

![Карточка Интернетометра](https://raw.githubusercontent.com/nightrus/ha-yandex-internetometr/main/docs/card.png)

## Авторы

Это форк интеграции **[ha-yainternetometr](https://github.com/ErilovNikita/ha-yainternetometr)**
и библиотеки **[yaspeedtest](https://github.com/ErilovNikita/yaspeedtest)**
([PyPI](https://pypi.org/project/yaspeedtest/)), автор обеих — **Никита Ерилов
([@ErilovNikita](https://github.com/ErilovNikita))**. Протокол работы с
Интернетометром, список тестовых серверов и метод замера пинга взяты из его
кода. Лицензия — Apache 2.0, как у оригинала (см. [LICENSE](LICENSE) и
[NOTICE](NOTICE)).

## Что исправлено

В `yaspeedtest` 0.1.7 и `ha-yainternetometr` 1.1.2 значения занижены:

- **Отдача.** Яндекс указывает размер тестов отдачи в килобайтах
  (`size=30720` = 30 МБ), а библиотека отправляла столько же *байт* — 30 КБ.
  Такая посылка уходит за доли секунды, библиотека возвращала 0, и интеграция
  подставляла запасной замер 1 МБ вместе с установкой соединения. Получалось
  ~90–160 Мбит/с почти на любом канале.
- **Загрузка.** Файлы качались с трёх серверов параллельно, но в результат
  шёл максимум *одного* потока, а не их сумма, — отсюда сильный разброс
  (у автора форка — от 60 до 930 Мбит/с на одном и том же канале).
  Кроме того, неудачная последняя попытка обнуляла результат сервера.

Здесь загрузка и отдача меряются как **суммарная скорость 6 параллельных
потоков** (по 2 на каждый из трёх серверов) за 8 секунд, первые 1,5 секунды
(разгон TCP) не учитываются. Отдача считается только по подтверждённым
сервером запросам. Пинг — медиана HTTP-запросов к лучшему серверу, как в
оригинале.

## Установка

HACS → ⋮ → «Пользовательские репозитории» →
`https://github.com/nightrus/ha-yandex-internetometr`, тип «Интеграция» →
скачать → перезапустить HA → Настройки → Устройства и службы → «Добавить
интеграцию» → «Яндекс Интернетометр».

Домен `yandex_internetometr` не пересекается с оригинальным `yainternetometr`,
обе интеграции можно поставить рядом и сравнить.

## Сущности

| сущность | |
|---|---|
| `sensor.internetometr_download` | загрузка, Мбит/с; атрибуты `servers`, `transferred_mb`, `measured_at` |
| `sensor.internetometr_upload` | отдача, Мбит/с |
| `sensor.internetometr_ping` | пинг, мс |
| `button.internetometr_run_test` | запустить замер; атрибут `in_progress` |
| `number.internetometr_test_interval` | интервал автозамера, мин (0 — только по кнопке), по умолчанию 30 |

Последние значения сохраняются после перезапуска HA.

**Трафик.** Один замер длится ~20 секунд и передаёт объём, пропорциональный
скорости: на 1 Гбит/с — около 1 ГБ в каждую сторону. При замере раз в 30 минут
это до ~100 ГБ в сутки, на лимитных тарифах увеличьте интервал.

Замер идёт с самого сервера Home Assistant: результат ограничен его сетевым
портом (1 Гбит/с ≈ 940 Мбит/с полезной скорости) и загрузкой процессора.

## Карточка

Интеграция сама подключает карточку, ресурс добавлять не нужно. Сущности она
находит сама:

```yaml
type: custom:yandex-internetometr-card
title: Интернет   # необязательно
```

Цвет значений: зелёный — отлично (≥ 300 Мбит/с, пинг ≤ 20 мс), светло-зелёный —
хорошо (≥ 50 Мбит/с, ≤ 40 мс), жёлтый — нормально (пинг ≤ 80 мс), красный —
плохо. Тап по значению открывает историю, внизу — интервал (−/+) и кнопка
«Измерить».
